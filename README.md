## 📌 Project Overview

**Responsive Travel Destination Explorer** is a modern travel discovery webpage designed to showcase beautiful destinations through an engaging and visually appealing interface.

The project features a carefully structured hero section, destination photography, informative destination cards, location details, price indicators, and clear calls to action.

Its responsive layout adapts to different screen sizes, providing a consistent browsing experience across desktop, tablet, and mobile devices.

The project demonstrates practical front-end development skills, with a strong focus on visual hierarchy, responsive layouts, image presentation, and clean CSS styling.

## ✨ Key Features

- **Modern Hero Section** – A visually engaging introduction with a prominent heading and call to action.
- **Destination Gallery** – Attractive destination cards featuring photographs and descriptions.
- **Featured Destinations** – Selected destinations receive additional visual emphasis.
- **Location Details** – Clear destination names and location indicators.
- **Price Indicators** – Example travel prices displayed for each destination.
- **Responsive Layout** – Adapts to desktop, tablet, and mobile screens.
- **Image Optimization Styling** – Consistent image presentation using `object-fit: cover`.
- **Modern Hover Effects** – Smooth transitions that enhance interaction.
- **Visual Consistency** – Carefully selected colours, spacing, typography, and card layouts.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Regalson001/Responsive-Travel-Destination-Explorer.git
```

### 2. Navigate into the project folder

```bash
cd Responsive-Travel-Destination-Explorer
```

### 3. Open the project

Open the folder in Visual Studio Code:

```bash
code .
```

### 4. Run the website

Open `index.html` in your browser.

You can also use the **Live Server** extension in Visual Studio Code for a convenient development preview.

## 📱 Responsive Design

The project is designed to provide a consistent experience across different devices.

- **Desktop:** Spacious destination cards arranged in a responsive gallery.
- **Tablet:** Adjusted grid columns and spacing.
- **Mobile:** Stacked or reduced-column layouts for comfortable browsing.

CSS media queries are used to adapt the layout to smaller screens.
